永磁同步电机 AI 设计助手 - 免安装便携版
========================================

使用方法
--------
1. 将整个文件夹解压到电脑或 U 盘上的普通目录。
2. 双击 PMSM-AI-Design-Assistant.exe。
3. 第一次打开时等待数秒，不需要安装 Python、Conda、VS Code 或 Maxwell。
4. 如果模型未自动加载，点击“一键训练模型”，完成后即可预测。
5. 参数趋势页会同时显示解析公式实线和 AI 代理虚线；断点表示设计不可行或超出训练范围。
6. 模型评估页中的 R²、MAE、RMSE 用于检查代理模型误差，不等同于真实样机或 FEA 精度。

目录说明
--------
- PMSM-AI-Design-Assistant.exe：图形界面主程序。
- _internal：Python、Qt 和科学计算运行库，请勿删除。
- artifacts：已训练模型和训练指标，请勿删除。
- 使用说明：见程序顶部的“使用说明”标签页。

注意事项
--------
- 支持 Windows 10/11 64 位，不支持 32 位 Windows。
- 本便携版只包含 GUI 预测功能，不包含 Maxwell FEA 采样库构建功能。
- 预测结果基于合成教学数据，不能替代有限元或实验验证。
- 部分杀毒软件可能对 PyInstaller 程序误报，请确认文件来源后再决定是否信任。
