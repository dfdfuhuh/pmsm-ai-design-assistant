# 课程要求映射

本表把课程报告要求拆分为“当前可验收证据”和“正式报告仍需补充的内容”。当前最小算法闭环已经实现。

| 课程要求 | 报告可验收证据 | 当前实现状态 |
| --- | --- | --- |
| 选题与专业相关，结合研究方向 | 以永磁同步电机几何、材料、电流和转速为输入，预测转矩、转矩脉动与效率 | 已实现表贴式 8 极 12 槽降阶模型和设计 GUI |
| 与大模型配合编程，程序具有 GUI | 大模型协作记录、提示词、代码审查记录、PyQt6 操作界面和运行截图 | 已实现工作台、趋势图、模型评估页并记录 AI 协作过程 |
| 使用一种 AI 模型完成算法 | 随机森林数据生成、训练、独立测试集评估和 GUI 推理链路 | 已实现随机森林训练、评价、保存、加载与 GUI 预测 |
| 使用 Python 并掌握面向对象程序设计 | 领域模型、数据生成器、代理模型、服务层和 GUI 组件各自封装 | 已按领域、数据、模型、服务和界面层拆分 |
| 推荐 PyQt、VS Code、Anaconda | 环境文件、依赖锁定、VS Code 配置、启动与测试说明 | 使用 PyQt6、VS Code、Miniconda 和 `conda-forge` 环境 |

## 后续报告应包含

- 课题背景、研究方向和设计目标。
- 参数范围、解析模型假设与合成数据生成方法。
- 随机森林训练设置、数据划分、指标和误差讨论。
- GUI 类结构、操作步骤和关键界面截图。
- 大模型参与环节、人工审查方式以及测试结果。
- 与有限元或实验数据交叉验证的计划和当前局限。
