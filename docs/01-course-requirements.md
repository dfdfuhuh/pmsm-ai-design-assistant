# 课程要求映射

本表把课程报告要求拆分为“当前预研证据”和“后续课程成果”。当前阶段只验证开发链路，不把规划功能写成已完成功能。

| 课程要求 | 后续可验收证据 | 当前预研状态 |
| --- | --- | --- |
| 选题与专业相关，结合研究方向 | 以永磁同步电机几何、材料、电流和转速为输入，预测转矩、转矩脉动与效率 | 已确定“PMSM AI 设计助手”选题和技术边界 |
| 与大模型配合编程，程序具有 GUI | 大模型协作记录、提示词、代码审查记录、PyQt6 操作界面和运行截图 | 已建立 AI 协作日志模板，完成 PyQt6 最小启动页 |
| 使用一种 AI 模型完成算法 | 随机森林数据生成、训练、独立测试集评估和 GUI 推理链路 | 已选择随机森林路线；算法尚未实现 |
| 使用 Python 并掌握面向对象程序设计 | 领域模型、数据生成器、代理模型、服务层和 GUI 组件各自封装 | 启动页、卡片组件和环境检查使用 Python 类与组合关系 |
| 推荐 PyQt、VS Code、Anaconda | 环境文件、依赖锁定、VS Code 配置、启动与测试说明 | 使用 PyQt6、VS Code、Miniconda 和 `conda-forge` 环境 |

## 后续报告应包含

- 课题背景、研究方向和设计目标。
- 参数范围、解析模型假设与合成数据生成方法。
- 随机森林训练设置、数据划分、指标和误差讨论。
- GUI 类结构、操作步骤和关键界面截图。
- 大模型参与环节、人工审查方式以及测试结果。
- 与有限元或实验数据交叉验证的计划和当前局限。
