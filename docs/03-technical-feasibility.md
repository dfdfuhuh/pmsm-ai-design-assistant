# 技术可行性预研

## 总体架构

后续版本采用分层结构：

- 领域层：描述设计参数、派生量和预测结果，负责单位与范围校验。
- 数据层：使用降阶解析关系生成样本，记录采样范围、随机种子和版本。
- 模型层：训练随机森林。可用一个多输出模型，也可按输出分别训练并评估。
- 服务层：组合数据、模型和结果解释，GUI 不直接承担科学计算。
- 界面层：PyQt6 输入表单、二维示意、指标卡、敏感性和模型评估视图分离。

这种拆分便于单元测试，也满足课程对面向对象程序设计的要求。

## 候选用建模参数

| 类别 | 参数 |
| --- | --- |
| 定子几何 | 外径、内径、铁芯轴向长度、槽数 |
| 转子与气隙 | 气隙长度、永磁体厚度、极对数、永磁材料参数 |
| 绕组 | 每相串联匝数、绕组系数、相电阻 |
| 工况 | 额定电流、电流角、转速、母线电压 |

具体范围必须依据解析模型假设、示例电机尺度和数值稳定性确定，不能先随意设定一个“看起来合理”的宽区间。

## 预测目标

- 电磁转矩，单位 N·m。
- 转矩脉动，使用百分比表示。
- 效率，使用百分比表示。

转矩可由同步电机基本关系构造；转矩脉动和损耗需要对槽极配合、电流角、铁耗和机械耗进行简化。每种简化都应在报告中标明，而不是把经验修正项描述成严格物理定律。

## 合成数据流程

1. 为每个输入指定有依据的上下界。
2. 使用固定随机种子进行均匀或拉丁超立方采样。
3. 计算稳定工况下的解析目标值。
4. 对明显违反物理约束的样本执行过滤和审计。
5. 保存参数表、生成脚本或哈希、版本和摘要统计。
6. 按训练、验证、测试集划分，避免同一工况泄漏到不同集合。

## 随机森林流程

- 基线模型：`RandomForestRegressor`，固定随机种子。
- 评价指标：每个目标分别报告 R²、MAE、RMSE。
- 可选分析：特征重要性、预测值与目标值散点图、残差分布。
- 调参边界：只在训练/验证集上进行，测试集留到最终评估。
- 持久化：保存模型、特征顺序、预处理配置和训练版本，避免输入列错位。

## 关键风险与验证

随机森林无法外推到训练范围之外，因此 GUI 必须阻止或警告超范围输入。合成目标可能过于平滑，导致模型指标虚高；应设置独立解析基准和噪声场景，条件允许时再使用有限元或实测数据验证。

## 当前实现结果

固定拓扑已确定为表贴式 8 极 12 槽小功率伺服电机。生成了 8000 条满足 300–3500 W 功率覆盖范围的样本，并按 70%/15%/15% 划分。三个随机森林在独立测试集上的 R² 分别约为 0.993、0.995 和 0.978。

当前结果证明方法链路和合成数据拟合可行，但仍不能证明真实电机泛化能力。下一阶段应优先获取有限元或实验样本进行外部验证，再决定是否扩展槽极组合、温度和多目标优化。
