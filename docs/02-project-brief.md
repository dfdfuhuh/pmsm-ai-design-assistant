# 项目说明

## 背景

永磁同步电机具有高效率、高功率密度等优点，其几何尺寸、永磁体参数、绕组和电流控制会共同影响输出性能。完整电磁设计通常依赖有限元分析，但课程项目需要兼顾专业相关性、代码可解释性和演示时间。

本项目拟建立轻量级设计分析原型：用户输入少量 PMSM 参数，界面展示代理模型的转矩、转矩脉动和效率预测，并辅助观察参数变化趋势。

## 目标用户

- 进行课程展示的电机方向学生。
- 希望快速理解参数趋势，但不把结果视为最终设计结论的研究入门者。
- 需要查看 Python、GUI、OOP 和机器学习完整实现链路的教师或评审。

## 当前阶段

当前只完成开发环境、仓库规范、预研文档和 PyQt6 启动页。环境自检可以运行，但界面中不包含真实电磁计算或 AI 推理。

## 后续最小版本

1. 定义经过范围校验的 PMSM 设计参数。
2. 实现有明确假设的降阶解析模型，并生成可复现合成数据。
3. 训练随机森林代理模型并保存评估结果。
4. 在 GUI 中展示预测值、模型状态和参数影响。
5. 导出单次设计结果和模型评价摘要。

## 非目标

- 不替代 Maxwell、JMAG 等有限元软件。
- 不宣称合成数据可达到实验精度。
- 不在预研阶段实现多目标优化或商业级电机设计流程。
- 不包含真实企业图纸、受版权保护的数据或许可证文件。

## 结果解释边界

后续合成数据由简化解析关系生成，随机森林主要学习该生成器中的参数映射。模型表现好只说明它拟合了合成规律，不能证明其对真实电机的泛化能力。任何对外展示都必须同时说明数据来源、参数范围和验证局限。
