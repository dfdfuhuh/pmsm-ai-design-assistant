# 合成数据与随机森林模型卡

记录日期：2026-11-18

## 用途

模型用于课程项目中的 PMSM 参数趋势演示和完整 Python 算法链路验证。固定结构为表贴式、8 极、12 槽、4 对极小功率伺服电机教学原型。

模型不是产品设计工具，也不能替代 Maxwell/JMAG 有限元计算、样机测试或经过认证的电磁设计软件。

## 输入范围

| 参数 | 范围 | 单位 |
| --- | --- | --- |
| 定子外径 | 80–120 | mm |
| 定子内径 | 45–75 | mm |
| 内外径差 | ≥30 | mm |
| 铁芯轴向长度 | 25–55 | mm |
| 气隙长度 | 0.30–0.80 | mm |
| 永磁体厚度 | 2–6 | mm |
| 每相串联匝数 | 40–120 | 匝 |
| 额定相电流 RMS | 2–10 | A |
| 电流超前角 | 0–30 | ° |
| 转速 | 1000–4000 | rpm |
| 永磁体剩磁 | 0.95–1.25 | T |
| 相电阻 | 0.20–1.20 | Ω |

数据集额外约束解析输出功率在 300–3500 W 内。GUI 对超出该功率覆盖范围的工况显示警告。

## 解析模型

简化磁路中的气隙磁密写为：

\[
B_\delta = \frac{B_r h_m}{h_m + \mu_r g k_s}
\]

其中 `B_r` 为剩磁，`h_m` 为磁钢厚度，`g` 为气隙，`μ_r=1.05`，饱和修正系数 `k_s=1.15`。

每极磁通由气隙磁密、极距、铁芯长度和叠片系数构造，相位永磁磁链再乘以每相匝数和绕组系数 `0.933`。平均转矩采用表贴式 PMSM 的稳态 dq 关系：

\[
T_e = \frac{3}{2}p\psi_f I_s\cos\beta
\]

效率由机械输出、铜耗、简化铁耗和机械耗计算。铁耗经验系数和机械耗系数是课程教学参数，不是材料厂家数据。

转矩脉动使用以下经验关系：

\[
R_{pp} \approx 2 + 1.4\frac{3}{h_m} + 0.6\frac{0.5}{g}
 + 0.02\beta + 0.2B_\delta
\]

该项只能解释为相对趋势指标，不代表严格齿槽转矩或有限元脉动结果。

## 数据

- 8000 条样本，拉丁超立方采样。
- 随机种子固定为 42。
- 参数范围、公式常数和 CSV SHA-256 位于 `data/pmsm_spm_8p12s_metadata.json`。
- 数据按 70%/15%/15% 划分训练、验证和测试集。
- 合成数据不加入人为噪声。

## 随机森林

| 设置 | 值 |
| --- | --- |
| 模型 | 每个目标一个 `RandomForestRegressor` |
| 树数量 | 200 |
| 最大深度 | 18 |
| 叶节点最小样本数 | 3 |
| 随机种子 | 42 |
| 输入特征 | 11 个设计参数 + 4 个物理派生量 |

物理派生量为气隙磁密、永磁磁链、电频率和机械角速度。

## 独立测试结果

| 目标 | R² | MAE | RMSE |
| --- | --- | --- | --- |
| 平均转矩 | 0.9928 | 0.0513 N·m | 0.0994 N·m |
| 转矩脉动 | 0.9951 | 0.0226 个百分点 | 0.0301 个百分点 |
| 效率 | 0.9778 | 0.8905 个百分点 | 1.2300 个百分点 |

高指标主要说明随机森林能拟合解析生成器，不说明其能够预测真实电机。

## 已知限制

- 未考虑磁路饱和、温度、谐波、端部效应、逆变器损耗和控制动态。
- 转矩脉动只采用经验趋势模型。
- 参数范围外不能外推。
- 数据缺少有限元或实验参照。
- 模型文件未提交，首次使用需训练。
