# 风险清单

| 类别 | 风险 | 可能性 | 影响 | 缓解措施 |
| --- | --- | --- | --- | --- |
| 物理建模 | 简化解析关系不能准确反映真实电机 | 高 | 高 | 明确教学原型边界；记录假设；用解析基准和可获得的数据交叉验证 |
| 数据 | 合成数据过于平滑，模型指标虚高 | 高 | 中 | 使用独立采样场景和合理噪声；报告生成器与模型误差，不只展示训练拟合 |
| 机器学习 | 随机森林外推能力弱 | 高 | 中 | GUI 限制输入范围；超范围时警告；不把边界结果用于设计判断 |
| 参数范围 | 随意扩大范围造成非物理样本 | 中 | 高 | 结合示例电机、几何约束和解析模型有效性逐项定界 |
| GUI | 计算阻塞界面或测试在无桌面环境卡住 | 中 | 中 | 计算与界面分离；长任务异步化；测试固定使用 offscreen 平台 |
| 环境 | Conda、PATH 或依赖版本漂移 | 中 | 中 | 使用 `environment.yml` 和锁定依赖；保留环境自检脚本 |
| 网络 | PyPI、GitHub 或 VS Code 市场连接不稳定 | 中 | 中 | 使用可访问镜像作为临时方案；完成安装后本地验证；不提交缓存 |
| GitHub | 误提交密钥、个人路径或大文件 | 低 | 高 | 提交前检查差异和忽略规则；公开仓库不放隐私配置 |
| 范围 | 预研扩张为完整报告和优化平台 | 中 | 中 | 当前只验收环境、文档、启动页和测试；其余内容分阶段决定 |
